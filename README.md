# Study RPG | Gamified Study & Adventure System

Study RPG is an interactive web application that combines study management with RPG gameplay. The goal is to make studying more engaging and motivating through game-based rewards.

Users can earn Action Points (AP) by completing study sessions or tasks. These points can be used to battle monsters. Defeating monsters rewards players with experience points (EXP) and gold, which can be used to level up characters, unlock skills, and purchase equipment.

## Website

**Play Study RPG:** https://an0124.github.io/study-rpg/

## Features

- **Focus Timer:** Use a Pomodoro timer or customize study sessions to earn AP.
- **Task Management:** Create study tasks, set difficulty levels, deadlines, and subtasks.
- **Turn-Based Combat:** Spend AP to attack, defend, heal, and battle monsters or bosses.
- **Character Progression:** Earn EXP and gold, level up characters, and unlock new skills.
- **Equipment Shop:** Purchase weapons, armor, and healing items using in-game gold.
- **Auto Save:** Automatically save study records and game progress using `localStorage`.
- **Demo Mode:** Experience the main features with a 15-second timer without affecting normal game progress.

## How to Play

1. Visit the **Study Room** to create study tasks or start a focus timer.
2. Complete study sessions or tasks to earn Action Points (AP).
3. Enter the **Dungeon** and use AP to battle monsters.
4. Defeat enemies to earn EXP and gold.
5. Level up your character, unlock skills, and purchase equipment to challenge stronger enemies.

For a quick demonstration, enable **Demo Mode** in the settings.

## Development

This project was developed using **Vibe Coding** with AI assistance.

The development process began with discussions with AI to define the requirements, including study management, combat mechanics, character progression, reward systems, and interface design.

Based on these requirements, the web application was implemented, tested, and refined through iterative improvements.

**Technologies Used:**
- HTML
- CSS
- JavaScript
- LocalStorage
- GitHub Pages

All code is integrated into a single `index.html` file. No additional installations, backend server, or database are required.

## Notes

Game progress and study records are stored locally in the user's browser. Data will not automatically sync across different browsers or devices.
